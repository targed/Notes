### **Conceptual Questions (Slide 65)**
  
  **Q1: Explain the key difference between a fully connected neural network and a CNN. Why are CNNs particularly suitable for image data?**
  *   **Answer:** In a Fully Connected (FC) network, every input pixel is connected to every neuron, leading to a massive "parameter explosion" that ignores spatial structure. A CNN uses a sliding window (Filter) that only looks at a small, local patch of pixels at a time. This preserves the 2D spatial relationships of the image (e.g., keeping the pixels of an eye together) and drastically reduces the number of weights to learn.
  
  **Q2: What is weight sharing in CNNs? Why does it significantly reduce the number of parameters?**
  *   **Answer:** Instead of learning a different weight for every single pixel, a CNN learns one small Filter (e.g., $3 \times 3 = 9$ weights). This single filter is "shared" as it slides across the entire image. Whether the image is $28 \times 28$ or $4K$ resolution, the filter still only requires 9 parameters!
  
  **Q3: Explain the purpose of pooling layers. What problem do they solve? What information is lost?**
  *   **Answer:** Pooling layers (like Max Pooling) shrink the spatial dimensions (width and height) of the feature maps. 
    *   *Problem Solved:* They reduce computational load and control overfitting by shrinking the number of parameters for the later layers.
    *   *Information Lost:* Exact spatial location. Max pooling keeps the "strongest" feature (e.g., "There is an edge here") but throws away the exact pixel coordinates of where that edge was inside the $2 \times 2$ window.
  
  **Q4: What is a feature map? How does it evolve across layers in a CNN?**
  *   **Answer:** A feature map is the 2D grid of numbers generated by sliding a filter over an image. Across layers, feature maps usually shrink in spatial size (Width $\times$ Height) due to pooling, but grow in Depth (Channels) as the network extracts more complex, abstract features (from simple lines to complex faces).

### **Math Questions: Parameter \& Size Counting (Slide 66)**
  
  **Q5: Given Input: $28 \times 28$, Filter: $3 \times 3$, Stride: 1, Padding: 1.**
  **(1) Compute output size.**
  *   *Formula:* $Output = \frac{Input - Filter + (2 \times Padding)}{Stride} + 1$
  *   *Calculation:* $\frac{28 - 3 + (2 \times 1)}{1} + 1 = \frac{27}{1} + 1 = \mathbf{28}$.
  *   *Answer:* The spatial size is **$28 \times 28$**. *(Note: Because $Padding=1$ on a $3 \times 3$ filter, the size stayed the same!)*
  
  **(2) If there are 10 filters, what is the output dimension?**
  *   *Answer:* Because there are 10 filters, there will be 10 feature maps. The final dimension is **$28 \times 28 \times 10$**.
  
  **Q6: A convolutional layer has 16 filters of size $3 \times 3$. Input has 3 channels (RGB). Compute the total number of parameters.**
  *   *Formula:* $Parameters = (\text{Filter Width} \times \text{Filter Height} \times \text{Input Channels} + 1 \text{ Bias}) \times \text{Number of Filters}$
  *   *Step 1 (Weights per filter):* $3 \times 3 \times 3 = 27$ weights.
  *   *Step 2 (Add Bias):* $27 + 1 = 28$ parameters per filter.
  *   *Step 3 (Total Filters):* $28 \times 16 = \mathbf{448}$ **total parameters.**
  
  **Q7: Assume $n1=16$, $n2=32$, $n3=4 \times 4 \times n2$. Compute the total number of parameters in this CNN model.**
  *(Based on the diagram on Slide 66)*
  *   **Conv_1 (Input $28 \times 28 \times 1$, Filter $5 \times 5$, 16 Filters):**
    *   $((5 \times 5 \times 1) + 1) \times 16 = (25 + 1) \times 16 = 26 \times 16 = \mathbf{416}$ parameters.
  *   **Max-Pooling 1:** $0$ parameters (Pooling has no weights to learn).
  *   **Conv_2 (Input 16 Channels, Filter $5 \times 5$, 32 Filters):**
    *   $((5 \times 5 \times 16) + 1) \times 32 = (400 + 1) \times 32 = 401 \times 32 = \mathbf{12,832}$ parameters.
  *   **Max-Pooling 2:** $0$ parameters.
  *   **Flatten Layer:** Shrinks the grid into a 1D vector. Size = $4 \times 4 \times 32 = \mathbf{512}$ neurons.
  *   **FC_3 (Fully Connected Layer):** The diagram connects the 512 flattened neurons to $n3$ hidden neurons. The prompt says $n3 = 4 \times 4 \times n2 = 512$. 
    *   *(Neurons $\times$ Neurons) + Bias*
    *   $(512 \times 512) + 512 = 262,144 + 512 = \mathbf{262,656}$ parameters.
  *   **FC_4 (Output Layer):** Connects the 512 hidden neurons to the 10 output classes.
    *   $(512 \times 10) + 10 = 5,120 + 10 = \mathbf{5,130}$ parameters.
  *   **Total Parameters in Network:** $416 + 12,832 + 262,656 + 5,130 = \mathbf{281,034}$ parameters.

### **Troubleshooting Questions (Slide 67)**
  
  **Q8: A student reports that their CNN has very high training accuracy, but very low test accuracy. What is the likely issue? Suggest at least three solutions.**
  *   **Issue:** The model is suffering from **Overfitting**. It has memorized the training data but failed to generalize.
  *   **Solutions (Pick 3):** 
    1.  Add **Dropout** layers to randomly turn off neurons and prevent reliance on specific paths.
    2.  Use **Data Augmentation** (flip, rotate, crop the images) to artificially increase dataset size.
    3.  Implement **Early Stopping** (stop training when validation error starts to rise).
    4.  Reduce model complexity (make the network shallower or use fewer filters).
  
  **Q9: CNNs are often described as having translation invariance.** 
  **(1) What does this mean?**
  *   *Answer:* It means the network can recognize an object (like a cat) regardless of where it is located in the picture. If the cat is in the top-left corner or the bottom-right corner, the network still sees it.
  **(2) Which components of CNN contribute to this property?**
  *   *Answer:* 
    1.  **Weight Sharing (Convolution):** Because the same filter slides across the entire image, it acts as a universal feature detector. If it detects a horizontal edge, it will detect it anywhere.
    2.  **Pooling:** Max pooling provides local spatial invariance. By taking the maximum value in a $2 \times 2$ grid, a feature can shift by a pixel or two in any direction and the output of the pooling layer remains exactly the same.
