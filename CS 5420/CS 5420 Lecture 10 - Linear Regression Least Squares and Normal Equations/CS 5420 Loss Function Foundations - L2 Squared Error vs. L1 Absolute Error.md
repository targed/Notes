## 1. Quick Review: Answers to Section 1 Checkpoints
  
  1. **Statistical Error ($\epsilon_i$) vs. Empirical Residual ($r_i$):**
  * The **statistical error** $\epsilon_i = y_i - f^*(x_i)$ is an unobservable theoretical random variable representing the true deviation of an observation from the population regression function:
   $$y_i = x_i^T w^* + \epsilon_i, \quad \text{where } \epsilon_i \sim \mathcal{N}(0, \sigma^2)$$
  * The **residual** $r_i = y_i - \hat{y}_i = y_i - x_i^T \hat{w}$ is an observable empirical quantity measuring the distance between the target and the prediction generated by our estimated parameter vector $\hat{w}$.
  2. **Why Polynomial Regression Is Mathematically a Linear Model:**
  * Linearity in statistical learning theory refers strictly to the **parameters $w$**, not the input coordinates $x$.
  * In a cubic model $\hat{y} = w_0 + w_1 x + w_2 x^2 + w_3 x^3$, the hypothesis function is linear in $w$:
   $$\frac{\partial \hat{y}}{\partial w_j} = x^j \quad (\text{Independent of the parameter vector } w)$$
  * The optimization problem over $w$ remains a convex quadratic program that can be solved via standard linear algebra.
  3. **The Homogeneous Coordinate Trick:**
  * Augmenting the design matrix with a column of ones ($X \in \mathbb{R}^{n \times (d+1)}$) absorbs the scalar intercept $w_0$ into the weight vector:
   $$\tilde{w} = [w_0, w_1, \dots, w_d]^T$$
  * This reduces the affine function $\hat{y}_i = w^T x_i + b$ to a single matrix multiplication $\hat{y} = Xw$, eliminating the need to derive and track separate bias derivatives.

## 3. Deconstructing the Five Architectural Dimensions (Slide 8)
  
  ---
### 1. Differentiability & Optimization Complexity
  * **$L_2$ Squared Loss ($r^2$):** 
  The function is continuously differentiable ($C^\infty$) across its entire domain:
  $$\frac{\partial}{\partial r} (r^2) = 2r$$
  The gradient is smooth and vanishes continuously as $r \to 0$.
  * **$L_1$ Absolute Loss ($|r|$):**
  The derivative is discontinuous at the origin ($r = 0$), forming a sharp "kink":
  $$\frac{\partial}{\partial r} |r| = \text{sign}(r) = \begin{cases} +1 & \text{if } r > 0 \\ -1 & \text{if } r < 0 \\ \text{undefined} & \text{if } r = 0 \end{cases}$$
  Because the classical gradient is undefined at zero, optimization cannot rely on standard unconstrained calculus. It requires **subgradient calculus** ($\partial |r|_{r=0} = [-1, 1]$) or conversion into a constrained **Linear Program (LP)** solved via interior point or simplex methods.
  
  ---
### 2. Closed-Form Analytical Tractability
  * Because the gradient of the $L_2$ loss is linear in $w$, setting $\nabla_w J(w) = 0$ yields a system of linear equations ($X^T X w = X^T y$). The optimal parameters can be written down directly using standard matrix algebra.
  * For $L_1$ loss, setting the subgradient to zero does not produce a system of linear equations; there is **no closed-form matrix solution**. Finding $w_{\text{MAE}}$ requires iterative numerical optimization.
  
  ---
### 3. Maximum Likelihood Estimation (MLE): Gaussian vs. Laplace Noise
  Why does minimizing squared error make sense statistically? The choice of loss function corresponds directly to an assumption about the distribution of measurement noise.
#### Case A: Gaussian Noise Assumption $\implies L_2$ Squared Loss
  Assume the true data-generating process is linear with additive, independent, and identically distributed (i.i.d.) zero-mean **Gaussian noise**:
  
  $$y_i = w^T x_i + \epsilon_i, \quad \text{where } \epsilon_i \sim \mathcal{N}(0, \sigma^2)$$
  
  The conditional probability density of observing $y_i$ given $x_i$ is:
  
  $$P(y_i \mid x_i; w, \sigma) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left( -\frac{(y_i - w^T x_i)^2}{2\sigma^2} \right)$$
  
  Taking the joint likelihood across all $N$ independent observations:
  
  $$L(w) = \prod_{i=1}^N \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left( -\frac{(y_i - w^T x_i)^2}{2\sigma^2} \right)$$
  
  To find the Maximum Likelihood Estimate, compute the **Negative Log-Likelihood (NLL)**:
  
  $$\text{NLL}(w) = -\ln L(w) = -\sum_{i=1}^N \left[ \ln\left(\frac{1}{\sqrt{2\pi\sigma^2}}\right) - \frac{(y_i - w^T x_i)^2}{2\sigma^2} \right]$$
  $$\text{NLL}(w) = \frac{N}{2}\ln(2\pi\sigma^2) + \frac{1}{2\sigma^2} \mathbf{\sum_{i=1}^N (y_i - w^T x_i)^2}$$
  
  Discarding constants independent of $w$:
  
  $$\arg\min_w \text{NLL}(w) \equiv \arg\min_w \mathbf{\sum_{i=1}^N (y_i - w^T x_i)^2} \quad (\mathbf{L_2 \text{ Least Squares}})$$
  
  $$\mathbf{\text{Ordinary Least Squares is the Maximum Likelihood Estimator under Gaussian noise.}}$$
  
  ---
#### Case B: Laplace Noise Assumption $\implies L_1$ Absolute Loss
  Now, assume the noise follows a heavy-tailed **Laplace distribution** with scale parameter $b$:
  
  $$P(y_i \mid x_i; w, b) = \frac{1}{2b} \exp\left( -\frac{|y_i - w^T x_i|}{b} \right)$$
  
  Evaluating the Negative Log-Likelihood:
  
  $$\text{NLL}(w) = -\ln L(w) = N\ln(2b) + \frac{1}{b} \mathbf{\sum_{i=1}^N |y_i - w^T x_i|}$$
  
  Minimizing NLL yields:
  
  $$\arg\min_w \text{NLL}(w) \equiv \arg\min_w \mathbf{\sum_{i=1}^N |y_i - w^T x_i|} \quad (\mathbf{L_1 \text{ Absolute Error}})$$
  
  $$\mathbf{\text{Mean Absolute Error is the Maximum Likelihood Estimator under Laplace noise.}}$$
  
  ---
### 4. Target Statistics: Conditional Mean vs. Conditional Median
  What central property of the target distribution does each loss function capture?
  
  * **Squared Loss ($L_2$):** Minimizing expected squared error recovers the **Conditional Mean**:
  $$c^* = \arg\min_c \mathbb{E}\left[(Y - c)^2\right] = \mathbf{\mathbb{E}[Y \mid X]}$$
  * **Absolute Loss ($L_1$):** Minimizing expected absolute error recovers the **Conditional Median**:
  $$c^* = \arg\min_c \mathbb{E}\left[|Y - c|\right] = \mathbf{\text{Median}(Y \mid X)}$$
  
  Because the median is an order statistic that is unaffected by extreme values, $L_1$ regression estimates the center of the distribution without being pulled by heavy tails.

### The Arithmetic of the Leverage Trap (Slide 9)
  Slide 9 highlights the quadratic penalty growth:
  
  $$\mathbf{\text{"A residual of 30 costs 900. A residual of 3 costs 9."}}$$
  $$\mathbf{\text{"The model will happily ruin its fit to ninety-nine good points to placate one bad one."}}$$
  
  * Consider an inlier with residual $r_1 = 3 \implies \text{Cost} = 3^2 = \mathbf{9}$.
  * Consider an outlier with residual $r_2 = 30 \implies \text{Cost} = 30^2 = \mathbf{900}$.
  * The residual is **$10\times$ larger**, but its loss penalty is **$100\times$ larger**.
#### Why the Fitted Line Collapses:
  * If the model rotates toward the outlier to cut its residual from $30$ down to $10$, the loss on that single point drops by:
  $$\Delta J_{\text{outlier}} = 900 - 100 = \mathbf{-800 \text{ points}}$$
  * In doing so, the model shifts away from $50$ clean inlier points, increasing each of their residuals from $1$ to $2$. The penalty increase across all $50$ points is:
  $$\Delta J_{\text{inliers}} = 50 \times (2^2 - 1^2) = 50 \times 3 = \mathbf{+150 \text{ points}}$$
  * **The Optimization Verdict:** 
  $$\Delta J_{\text{total}} = -800 + 150 = \mathbf{-650 \text{ points (Net Loss Improvement!)}}$$
  * The least-squares optimizer considers this severe distortion a massive improvement. It willingly ruins its fit on 50 legitimate observations to placate a single corrupted measurement.
  
  Slide 9 concludes:
  $$\mathbf{\text{"Outlier handling is not cosmetic when your loss is squared."}}$$

## 5. The Robust Middle Ground: Huber Loss (The Graduate Fill-In)
  
  How do modern production pipelines balance the differentiability of $L_2$ loss with the outlier resilience of $L_1$ loss? They use **Huber Loss (1964)**:
  
  $$L_\delta(r) = \begin{cases} \frac{1}{2} r^2 & \text{if } |r| \le \delta \quad (\text{Quadratic for small errors}) \\ \delta \left(|r| - \frac{1}{2}\delta\right) & \text{if } |r| > \delta \quad (\text{Linear for large errors}) \end{cases}$$
  
  ```
                          The Huber Compromise
       Penalty
          ▲
          │    Linear Tail: Slope = δ           Linear Tail: Slope = δ
          │         \                               /
          │          \                             /
          │           \       ╭───────────╮       /
          │            \    ╭─╯  L2 Basin ╰─╮    /
          │             \───╯   |r| ≤ δ     ╰───/
          └──────────────────────────────────────────────▶ Residual r
                            -δ              δ
  ```
  
  * **Near the Origin ($|r| \le \delta$):** Pure quadratic $L_2$ error. It is continuously differentiable, admits a unique global minimum, and avoids the optimization instabilities of $L_1$'s non-differentiable kink at zero.
  * **In the Tails ($|r| > \delta$):** Transitions smoothly into a linear $L_1$ penalty with constant slope $\delta$. Extreme outliers generate linear penalties rather than explosive quadratic penalties, preventing high-leverage points from dominating the parameter updates.
