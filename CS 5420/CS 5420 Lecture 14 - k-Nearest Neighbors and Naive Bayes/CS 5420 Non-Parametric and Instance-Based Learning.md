## 1. Algorithmic Foundations: Instance-Based Learning (Slide 2)
  
  Slide 2 introduces the fundamental premise of instance-based learning:
  
  $$\mathbf{\text{"The } k\text{NN classifier is a very intuitive method: examples are classified based on their similarity with training data."}}$$
  
  ```
                    The k-NN Classification Principle (Slide 2)
  ┌────────────────────────────────────────────────────────────────────────┐
  │ Given:                                                                 │
  │   • A training dataset of labeled pairs: 𝒟 = {(x_i, y_i)}ᵢ₌₁ⁿ          │
  │   • An unlabeled query observation: x_u ∈ ℝᵈ                           │
  │   • A distance metric function: d(x_u, x_i)                            │
  │   • An integer neighborhood size parameter: k                          │
  ├────────────────────────────────────────────────────────────────────────┤
  │ Operation:                                                             │
  │   1. Compute distances from x_u to all n stored training points.       │
  │   2. Identify the k closest instances: 𝒩_k(x_u) ⊂ 𝒟                    │
  │   3. Predict majority class via mode voting:                           │
  │                      ŷ_u = argmax_c ∑_{i ∈ 𝒩_k(x_u)} 𝟙{y_i == c}       │
  └────────────────────────────────────────────────────────────────────────┘
  ```
  
  Slide 2 notes: *"The $k\text{NN}$ only requires an integer $k$, a set of labeled examples, and a measure of closeness."*
  
  Unlike linear models or neural networks, $k$-NN is **non-parametric**: it does not assume that the data was generated by a fixed parametric family (e.g., $y = w^T x + b$). The number of effective parameters is not fixed; it grows dynamically with sample size $n$.

## 2. Lazy vs. Eager Learning: The Systems Trade-Off (Slide 3)
  
  Slide 3 presents an essential systems comparison between classical parametric estimators and nearest-neighbor classifiers:
  
  $$\mathbf{\text{"Store the training set. To predict, find the } k \text{ closest points and let them vote."}}$$
  $$\mathbf{\text{"No fitting step: training is free, and every prediction scans all } n \text{ stored points."}}$$
  
  ```
                       Lazy vs. Eager Computational Complexity
  ┌───────────────────────────┬────────────────────────────┬─────────────────────────────┐
  │ Dimension                 │ Eager Learning (Logistic)  │ Lazy Learning (k-NN)        │
  ├───────────────────────────┼────────────────────────────┼─────────────────────────────┤
  │ Training Phase (.fit())   │ Slow & Heavy:              │ Free / Instant:             │
  │                           │ Iterative gradient descent │ Simply loads and stores     │
  │                           │ over epochs: 𝒪(epochs·n·d) │ pointers in RAM: 𝒪(1)       │
  ├───────────────────────────┼────────────────────────────┼─────────────────────────────┤
  │ Inference Phase (.predict)│ Fast & Lightweight:        │ Slow & Memory-Bound:        │
  │                           │ Single inner product dot   │ Exhaustive linear scan over │
  │                           │ evaluation: 𝒪(d)           │ ALL n training points:𝒪(n·d)│
  ├───────────────────────────┼────────────────────────────┼─────────────────────────────┤
  │ Model Storage Footprint   │ Minimal:                   │ Massive:                    │
  │                           │ Retains only weights w:    │ Must retain the ENTIRE      │
  │                           │ 𝒪(d) floats                │ dataset matrix: 𝒪(n · d)    │
  └───────────────────────────┴────────────────────────────┴─────────────────────────────┘
  ```
### The Production Inference Bottleneck:
  * For an eager model (like Logistic Regression), once training finishes, the original dataset $\mathcal{D}$ can be deleted from disk; inference requires only the weight vector $w \in \mathbb{R}^{d+1}$.
  * For $k$-NN, **the training data IS the model**.
  * In production, if $n = 10{,}000{,}000$ and $d = 100$, scoring a single incoming query point requires computing $10$ million 100-dimensional Euclidean distances. In latency-critical systems ($<10\text{ ms}$ response windows), brute-force $k$-NN is computationally infeasible without specialized tree indices (e.g., $k\text{-d}$ trees, Ball trees) or approximate nearest neighbor algorithms (HNSW, FAISS).

## 3. The Neighborhood Progression: $1$-NN to $5$-NN (Slides 4–7)
  
  Slides 4 through 7 illustrate the decision boundary mechanics as neighborhood size $k$ expands:
  
  ```
                      Neighborhood Enclosure Progression
     1-Nearest Neighbor (Slide 4)                  3-Nearest Neighbor (Slide 6)
  Feature x₂                                    Feature x₂
      ▲                                             ▲
      │       ○                                     │       ○
      │     ●   ○                                   │     ●   ○
      │   ╭─●─╮                                     │   ╭───●───╮
      │   │ ★ │  Prediction: ● (Red)                │  │  ★     │  Votes: 2 Red, 1 Yellow
      │   ╰───╯                                     │  │ ●     ○│  Prediction: ● (Red)
      │       ○                                     │   ╰───○───╯
      └────────────────────────▶ Feature x₁         └────────────────────────▶ Feature x₁
     Radius expands to capture 1 point             Radius expands to capture 3 points
  ```
  
  ---
### A. The $1$-NN Regime & Voronoi Tessellations (Slide 4)
  * When $k = 1$, the feature space is partitioned into a **Voronoi Tessellation**: a collection of convex polyhedral cells where every point inside a cell is closer to that cell's generating training instance than to any other training point.
  * **The Memorization Property:**
  $$\hat{y}(x_i) = y_i \quad \forall \; (x_i, y_i) \in \mathcal{D}_{\text{train}}$$
  The training error of a $1$-NN classifier is **identically zero** ($\text{Train Error} = 0.0$).
  * **The Noise Vulnerability:** If a training instance has a corrupted label or sits in the feature space as an extreme outlier, $1$-NN carves an isolated decision island around that single noisy point, fracturing the global decision boundary.
  
  ---
### B. Why Even $k$ Is Disallowed in Binary Classification (Slide 5)
  Slide 5 notes:
  $$\mathbf{\text{"2-Nearest Neighbor: } k \text{ even not used in practice."}}$$
  
  * If the target is binary ($C = 2$) and an even neighborhood size is chosen (e.g., $k = 2$ or $k = 4$), the neighborhood can produce a **$50/50$ voting deadlock** (e.g., 1 neighbor votes Class 0, and 1 neighbor votes Class 1).
  * Breaking ties requires arbitrary secondary heuristics (such as defaulting to the closer neighbor, falling back to global class priors, or tossing a coin).
  * **The Engineering Rule:** In binary classification, always choose **odd values of $k$** ($k \in \{1, 3, 5, 7, \dots\}$) to mathematically eliminate the possibility of a tie vote.

## 4. The Bias-Variance Trade-Off as a Function of $k$ (Slide 8)
  
  Slide 8 details the core theoretical trade-off governing neighborhood size:
  
  $$\mathbf{\text{"Small } k \text{ Overfits, Large } k \text{ Underfits"}}$$
  
  ```
  ┌────────────────────────────────────────────────────────────────────────┐
  │ Slide 8 Propositions:                                                  │
  │                                                                        │
  │ • Larger k  ──▶  Predicted label is more stable (Low Variance, High Bias)│
  │ • Smaller k ──▶  Predicted label is more accurate (Low Bias, High Var) │
  └────────────────────────────────────────────────────────────────────────┘
  ```
  
  ```
                     The Bias-Variance Spectrum in k-NN
    k = 1 (Extreme Overfitting)                        k = n (Extreme Underfitting)
  ┌─────────────────────────────────┐               ┌─────────────────────────────────┐
  │ • Model Capacity: Maximal       │               │ • Model Capacity: Zero          │
  │ • Effective Parameters: n       │               │ • Effective Parameters: 1       │
  │ • Bias: Low (zero on train)     │      vs.      │ • Bias: High (Ignores features) │
  │ • Variance: Extreme             │               │ • Variance: Zero (Constant)     │
  │ • Decision Boundary: Convoluted,│               │ • Decision Boundary: Disappears!│
  │   island-riddled, noisy         │               │   Predicts global majority class│
  └─────────────────────────────────┘               └─────────────────────────────────┘
  ```
  
  ---
### Mathematical Model Complexity: Effective Degrees of Freedom
  In parametric linear regression, model complexity is determined by the number of features ($d + 1$). In $k$-NN, model complexity is governed inversely by the neighborhood size:
  
  $$\mathbf{\text{Effective Degrees of Freedom} \approx \frac{n}{k}}$$
  
  1. **When $k = 1$:**
   $$\text{Degrees of Freedom} \approx \frac{n}{1} = n$$
   The model has as many degrees of freedom as there are observations in the dataset. It fits local idiosyncrasies, exhibiting low bias but extreme variance.
  2. **As $k \to n$:**
   $$\text{Degrees of Freedom} \approx \frac{n}{n} = 1$$
   The neighborhood expands to encompass the entire dataset. The local density information disappears; for every query point in the universe, the model predicts the global majority class. The boundary becomes completely rigid, exhibiting high bias and zero variance.

## 5. The Asymptotic Bayes Error Bound: Cover-Hart Theorem (The Graduate Fill-In)
  
  How good can a $1$-Nearest Neighbor classifier be when given infinite data?
  
  In 1967, Thomas Cover and Peter Hart proved one of the most famous results in statistical learning theory:
  
  ```
  ┌────────────────────────────────────────────────────────────────────────┐
  │ The Cover-Hart Theorem (1967):                                         │
  │                                                                        │
  │ Let R* be the Bayes Optimal Error Rate (the irreducible minimum error  │
  │ achieved by an omniscient model knowing the true posterior P(Y|X)).    │
  │                                                                        │
  │ As the sample size approaches infinity (n ──▶ ∞), the expected error   │
  │ of a 1-Nearest Neighbor classifier (R_1NN) is bounded by:              │
  │                                                                        │
  │                 R*  ≤  R_1NN  ≤  2 R* (1 - R*)  ≤  2 R*                │
  └────────────────────────────────────────────────────────────────────────┘
  ```
### Theoretical Implications:
  * **The Lower Bound ($R^*$):** No classifier can outperform the Bayes error rate due to inherent class overlap.
  * **The Upper Bound ($2 R^*$):** In the asymptotic limit of infinite data, the simple $1$-NN rule—which uses zero parametric assumptions—is **guaranteed to have an error rate no worse than twice the optimal Bayes error**. If the Bayes error is $R^* = 5\%$, a $1$-NN classifier with sufficient data is mathematically guaranteed to achieve an error rate under $10\%$.
