## Sections 1.1 and 1.2: Systems of Linear Equations, Row Reduction, and Echelon Forms
### What is Linear Algebra?
  
  **Definition (Merriam-Webster):** Linear Algebra is a branch of mathematics that is concerned with mathematical structures closed under the operations of addition and scalar multiplication and that includes the theory of systems of linear equations, matrices, determinants, vector spaces, and linear transformations.
### Systems of Linear Equations
  
  A **linear equation** is an equation that can be written in the form:
  
  $a_1x_1 + a_2x_2 + ... + a_nx_n = b$
  
  where:
  
  *   $a_1, a_2, ..., a_n$ are the coefficients (real or complex numbers).
  *   $x_1, x_2, ..., x_n$ are the variables.
  *   $b$ is the constant term.
  
  A **system of linear equations** is a collection of one or more linear equations involving the same variables $x_1, x_2, ..., x_n$.
  
  A **solution** of the system is an ordered n-tuple that satisfies all the equations in the system. The **solution set** of the system is the collection of all possible solutions of the system.
  
  **Possible Solution Sets for a System of Linear Equations**
  
  A system of linear equations can have:
  
  1. **No solution:** The system is said to be **inconsistent**.
  2. **Exactly one solution:** The system is said to be **consistent** and has a unique solution.
  3. **Infinitely many solutions:** The system is said to be **consistent** and has infinitely many solutions.
### Example 1
  
  Solve the following system of linear equations using elimination:
  
  $x_1 + 2x_2 + 3x_3 = 4$
  $4x_1 + 5x_2 + 6x_3 = 7$
  $7x_1 + 8x_2 + 10x_3 = 10$
  
  **Matrices**
  
  A **matrix** is a rectangular array of numbers. The plural of matrix is **matrices**.
  
  An $m \times n$ matrix has $m$ rows and $n$ columns.
  
  **Coefficient Matrix and Augmented Matrix**
  
  *   **Coefficient Matrix:** A matrix containing only the coefficients of the variables in a system of linear equations.
  *   **Augmented Matrix:** A matrix containing the coefficients of the variables and the constant terms of a system of linear equations.
  
  For Example 1, the coefficient matrix and augmented matrix are as follows:
  
  Coefficient Matrix:
  $\begin{bmatrix} 1 & 2 & 3 \\ 4 & 5 & 6 \\ 7 & 8 & 10 \end{bmatrix}$
  
  Augmented Matrix:
  $\begin{bmatrix} 1 & 2 & 3 & 4 \\ 4 & 5 & 6 & 7 \\ 7 & 8 & 10 & 10 \end{bmatrix}$
### Elementary Row Operations
  
  There are three types of elementary row operations that can be performed on a matrix:
  
  1. **Replacement:** Replace one row by the sum of itself and a multiple of another row.
  2. **Interchange:** Interchange (swap) two rows.
  3. **Scaling:** Multiply all entries in a row by a nonzero constant.
  
  **Row Equivalence**
  
  Two matrices are called **row equivalent** if there exists a sequence of elementary row operations that transforms one matrix into the other.
  
  **Important Theorem:** If the augmented matrices of two linear systems are row equivalent, then the two systems have the same solution set.
  
  **Note:** All elementary row operations are reversible!
### Solving the System (Example 1 continued)
  
  To solve the system, we apply elementary row operations to the augmented matrix to transform it into a simpler form.
### Echelon Forms
  
  A rectangular matrix is in **(row) echelon form** if it has the following properties:
  
  1. All nonzero rows are above any rows of all zeros.
  2. Each leading entry of a row is in a column to the right of the leading entry of the row above it. (The leading entry of a row is the first nonzero entry.)
  3. All entries in a column below a leading entry are zeros.
  
  A matrix in echelon form is in **reduced (row) echelon form** if it also satisfies the following conditions:
  
  4. The leading entry in each nonzero row is 1.
  5. Each leading 1 is the only nonzero entry in its column.
  
  **Uniqueness of Reduced Echelon Form**
  
  Each matrix is row equivalent to one and only one reduced echelon matrix.
  
  **Note:** While the echelon form of a matrix is not unique, any echelon form of a matrix will lead to the same reduced echelon form.
### Pivot Positions
  
  *   A **pivot position** in a matrix is a location that corresponds to a leading 1 in the reduced echelon form of the matrix.
  *   A **pivot column** of the matrix is a column that contains a pivot position.
  
  Even though echelon form is not unique, any echelon form of a matrix will result in leading entries in the same positions – the pivot positions.
### The Row Reduction Algorithm
  
  The **Row Reduction Algorithm** provides an efficient procedure for transforming a matrix into either echelon or reduced echelon form.
  
  **Steps:**
  
  1. Begin with the leftmost nonzero column. This is a pivot column, and the pivot position is at the top.
  2. Select a nonzero entry in the pivot column as a pivot. If necessary, interchange rows to move this entry into the pivot position.
  3. Use row replacement operations to create zeros in all positions below the pivot.
  4. Ignore the row containing the pivot and all rows (if any) above it. Repeat steps 1-3 for the remaining submatrix. Continue this process until there are no more nonzero rows to modify. At this point the matrix is in echelon form.
  5. Beginning with the rightmost pivot and working to the left, apply scaling operations to make each pivot a 1 and use replacement operations to create zeros above each pivot.
  
  After step 5, the matrix is now in reduced echelon form.

### Basic and Free Variables
  
  *   **Basic variables:** The variables corresponding to pivot columns in an augmented matrix.
  *   **Free variables:** The remaining variables, if any.
### Example 3
  
  Find the general solution of the linear system whose augmented matrix has been row reduced to:
  
  $\begin{bmatrix} 1 & 0 & 2 & 0 & -1 \\ 0 & 1 & -3 & 0 & 4 \\ 0 & 0 & 0 & 1 & 1 \end{bmatrix}$
### Existence and Uniqueness
  
  **Fundamental Questions about a Linear System:**
  
  1. **Existence:** Does at least one solution exist?
  2. **Uniqueness:** If a solution exists, is it unique?
  
  **Existence and Uniqueness Theorem**
  
  *   A linear system is consistent if and only if the rightmost column of the augmented matrix is **not** a pivot column.
  *   If the linear system is consistent, then:
    *   It will have exactly one solution if there are no free variables.
    *   It will have infinitely many solutions if there are one or more free variables.
