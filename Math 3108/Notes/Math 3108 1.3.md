## Section 1.3: Vectors
### Vectors
  
  A **vector** is a matrix with only one column or, alternatively, an ordered list of numbers.
  
  **Notation:**
  
  *   In printed materials, vectors are usually denoted by lowercase boldface letters (e.g., **v**).
  *   In handwritten materials, vectors are usually denoted with an arrow above the lowercase letter (e.g., $\vec{v}$).
  
  **Example:**
  
  $\mathbf{v} = \begin{bmatrix} v_1 \\ v_2 \end{bmatrix}$ or $\vec{v} = \begin{bmatrix} v_1 \\ v_2 \end{bmatrix}$
### Real Vectors
  
  *   $\mathbb{R}^2$: The set of all vectors with two entries where both entries are real numbers.
  *   $\mathbb{R}^3$: The set of all vectors with three entries where all three entries are real numbers.
  *   $\mathbb{R}^n$: The set of all vectors with *n* entries where all *n* entries are real numbers.
### Visualizing Vectors
  
  A vector $\begin{bmatrix} a \\ b \end{bmatrix}$ in $\mathbb{R}^2$ can be identified with the point $(a, b)$ in the plane.
  
  It is often useful to think of $\begin{bmatrix} a \\ b \end{bmatrix}$ as the directed line segment from $(0, 0)$ to $(a, b)$.
  
  **Example:**
  
  The vector $\begin{bmatrix} 2 \\ 1 \end{bmatrix}$ can be visualized as an arrow from the origin (0, 0) to the point (2, 1) in the Cartesian plane.

### Algebraic Properties of $\mathbb{R}^n$
  
  For all vectors $\mathbf{u}, \mathbf{v}, \mathbf{w}$ in $\mathbb{R}^n$ and all scalars $c$ and $d$, the following properties hold:
  
  1. **Commutativity of Vector Addition:** $\mathbf{u} + \mathbf{v} = \mathbf{v} + \mathbf{u}$
  2. **Associativity of Vector Addition:** $(\mathbf{u} + \mathbf{v}) + \mathbf{w} = \mathbf{u} + (\mathbf{v} + \mathbf{w})$
  3. **Additive Identity:** $\mathbf{u} + \mathbf{0} = \mathbf{0} + \mathbf{u} = \mathbf{u}$
  4. **Additive Inverse:** $\mathbf{u} + (-\mathbf{u}) = (-\mathbf{u}) + \mathbf{u} = \mathbf{0}$
  5. **Distributivity of Scalar Multiplication over Vector Addition:** $c(\mathbf{u} + \mathbf{v}) = c\mathbf{u} + c\mathbf{v}$
  6. **Distributivity of Scalar Addition over Scalar Multiplication:** $(c + d)\mathbf{u} = c\mathbf{u} + d\mathbf{u}$
  7. **Associativity of Scalar Multiplication:** $c(d\mathbf{u}) = (cd)\mathbf{u}$
  8. **Scalar Multiplication Identity:** $1\mathbf{u} = \mathbf{u}$
### Linear Combinations
  
  Given vectors $\mathbf{v}_1, \mathbf{v}_2, ..., \mathbf{v}_p$ in $\mathbb{R}^n$ and scalars $c_1, c_2, ..., c_p$, the vector $\mathbf{y}$ defined by:
  
  $\mathbf{y} = c_1\mathbf{v}_1 + c_2\mathbf{v}_2 + ... + c_p\mathbf{v}_p$
  
  is called a **linear combination** of the vectors $\mathbf{v}_1, \mathbf{v}_2, ..., \mathbf{v}_p$ with **weights** $c_1, c_2, ..., c_p$.

### Vector Equations
  
  A **vector equation**
  
  $x_1\mathbf{a}_1 + x_2\mathbf{a}_2 + ... + x_n\mathbf{a}_n = \mathbf{b}$
  
  has the same solution set as the linear system whose augmented matrix is
  
  $\begin{bmatrix} \mathbf{a}_1 & \mathbf{a}_2 & ... & \mathbf{a}_n & \mathbf{b} \end{bmatrix}$.
### Span
  
  If $\mathbf{v}_1, ..., \mathbf{v}_p$ are in $\mathbb{R}^n$, then the set of all linear combinations of $\mathbf{v}_1, ..., \mathbf{v}_p$ is denoted by **Span**{$\mathbf{v}_1, ..., \mathbf{v}_p$} and is called the **subset of** $\mathbb{R}^n$ **spanned by** $\mathbf{v}_1, ..., \mathbf{v}_p$.
  
  Equivalently, Span{$\mathbf{v}_1, ..., \mathbf{v}_p$} is the set of all vectors that can be written in the form:
  
  $c_1\mathbf{v}_1 + c_2\mathbf{v}_2 + ... + c_p\mathbf{v}_p$
  
  where $c_1, ..., c_p$ are scalars.

### The Span of One Vector
  
  If $\mathbf{v}$ is a nonzero vector in $\mathbb{R}^2$ (or $\mathbb{R}^3$), then Span{$\mathbf{v}$} is the set of all points on the line in $\mathbb{R}^2$ (or $\mathbb{R}^3$) passing through $\mathbf{v}$ and the origin.
### The Span of Two Vectors in $\mathbb{R}^2$
  
  If $\mathbf{u}$ and $\mathbf{v}$ are nonzero vectors in $\mathbb{R}^2$, then Span{$\mathbf{u, v}$} is either:
  
  *   A line through the origin and $\mathbf{u}$ if $\mathbf{v}$ is a constant multiple of $\mathbf{u}$.
  *   All of $\mathbb{R}^2$ if $\mathbf{v}$ is not a constant multiple of $\mathbf{u}$.
### The Span of Two Vectors in $\mathbb{R}^3$
  
  If $\mathbf{u}$ and $\mathbf{v}$ are nonzero vectors in $\mathbb{R}^3$, then Span{$\mathbf{u, v}$} is either:
  
  *   A line through the origin and $\mathbf{u}$ if $\mathbf{v}$ is a constant multiple of $\mathbf{u}$.
  *   The plane containing the origin, $\mathbf{u}$, and $\mathbf{v}$ if $\mathbf{v}$ is not a constant multiple of $\mathbf{u}$.
