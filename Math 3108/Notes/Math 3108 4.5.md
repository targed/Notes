## Section 4.5: The Dimension of a Vector Space
### A Theorem from Section 4.4
  
  Let $\mathcal{B} = \{\mathbf{b}_1, ..., \mathbf{b}_n\}$ be a basis for a vector space $V$. This vector space $V$ might not be $\mathbb{R}^n$. Then, the coordinate mapping $\mathbf{x} \mapsto [\mathbf{x}]_\mathcal{B}$ is a one-to-one linear transformation from $V$ onto $\mathbb{R}^n$.
  
  Recall that a one-to-one linear transformation from a vector space $V$ onto a vector space $W$ is called an isomorphism from $V$ onto $W$.
### Theorems
  
  *   If a vector space $V$ has a basis $\mathcal{B} = \{\mathbf{b}_1, ..., \mathbf{b}_n\}$, then any set in $V$ containing more than $n$ vectors must be linearly dependent.
  *   If a vector space $V$ has a basis with $n$ vectors, then every basis of $V$ must have exactly $n$ vectors.
### The Dimension of a Vector Space
  
  *   If $V$ is spanned by a finite set, then $V$ is said to be **finite-dimensional**, and the **dimension** of $V$ (written as $\text{dim } V$) is the number of vectors in a basis for $V$.
  *   The dimension of the zero vector space $\{\mathbf{0}\}$ is defined to be zero.
  *   If $V$ is not spanned by a finite set, then $V$ is said to be **infinite-dimensional**.
### Example 1
  
  Find a basis and state the dimension of the vector space.
  
  $V = \left\{ \begin{bmatrix} a - 4b - 2c \\ 2a + 5b - 4c \\ -a + 2c \\ -3a + 7b + 6c \end{bmatrix} : a, b, c \text{ real} \right\}$
  
  **Solution:**
  
  1.  **Rewrite as a linear combination:**
  
    $\begin{bmatrix} a - 4b - 2c \\ 2a + 5b - 4c \\ -a + 2c \\ -3a + 7b + 6c \end{bmatrix} = a\begin{bmatrix} 1 \\ 2 \\ -1 \\ -3 \end{bmatrix} + b\begin{bmatrix} -4 \\ 5 \\ 0 \\ 7 \end{bmatrix} + c\begin{bmatrix} -2 \\ -4 \\ 2 \\ 6 \end{bmatrix}$
  
  2.  **Form a matrix A with the vectors as columns:**
  
  $A = \begin{bmatrix} 1 & -4 & -2 \\ 2 & 5 & -4 \\ -1 & 0 & 2 \\ -3 & 7 & 6 \end{bmatrix}$
  
  3.  **Find pivot columns of A to get a basis for Col A:**
  
  $\begin{bmatrix} 1 & -4 & -2 \\ 2 & 5 & -4 \\ -1 & 0 & 2 \\ -3 & 7 & 6 \end{bmatrix} \sim \begin{bmatrix} 1 & -4 & -2 \\ 0 & 13 & 0 \\ 0 & -4 & 0 \\ 0 & -5 & 0 \end{bmatrix} \sim \begin{bmatrix} 1 & -4 & -2 \\ 0 & 1 & 0 \\ 0 & 0 & 0 \\ 0 & 0 & 0 \end{bmatrix}$
  
  The first two columns are pivot columns.
  
  4. **Basis and Dimension:**
    Basis for V: $ \left\{ \begin{bmatrix} 1 \\ 2 \\ -1 \\ -3 \end{bmatrix}, \begin{bmatrix} -4 \\ 5 \\ 0 \\ 7 \end{bmatrix} \right\}$
  
    The dimension of $V$ is the number of vectors in the basis, so $\text{dim } V = 2$.
### The Dimension of a Subspace
  
  Let $H$ be a subspace of a finite-dimensional vector space $V$. Any linearly independent set in $H$ can be expanded (if necessary) to form a basis for $H$. Additionally, $H$ is finite-dimensional and $\text{dim } H \leq \text{dim } V$.
### Example 2
  
  The first four Laguerre polynomials are $1$, $1-t$, $2 - 4t + t^2$, and $6 - 18t + 9t^2 - t^3$. Show that these polynomials form a basis $\mathcal{B}$ for $\mathbb{P}_3$. Then, find the coordinate vector for $\mathbf{p}(t) = 7 - 8t + 3t^2$ relative to the basis $\mathcal{B}$.
  
  **Solution:**
  1. Check Linear Independence.
  Convert to coordinate vectors:
  $\begin{bmatrix} 1 \\ 0 \\ 0 \\ 0\end{bmatrix}, \begin{bmatrix} 1 \\ -1 \\ 0 \\ 0\end{bmatrix}, \begin{bmatrix} 2 \\ -4 \\ 1 \\ 0\end{bmatrix}, \begin{bmatrix} 6 \\ -18 \\ 9 \\ -1\end{bmatrix}$
  Form a matrix:
  $A = \begin{bmatrix} 1 & 1 & 2 & 6\\ 0 & -1 & -4 & -18\\ 0 & 0 & 1 & 9 \\ 0 & 0 & 0 & -1\end{bmatrix}$
  This is in echelon form, and we can see all columns have a pivot. Therefore, these vectors are linearly independent.
  
  2. Show it spans P3
  We know P3 requires 4 linearly independent vectors to span it. We also know that if a set contains more vectors than there are entries in each vector, then the set is automatically linearly dependent. Since we only have 4 entries per vector and our number of vectors is 4, which is equal to the number of entries, and the set is linearly independent, then the set will span P3.
  
  3. Find coordinate vector for p(t).
  $p(t) = 7 - 8t + 3t^2 + 0t^3$
  We need to find coefficients.
  $c_1(1) + c_2(1-t) + c_3(2-4t+t^2) + c_4(6-18t+9t^2-t^3) = 7 - 8t + 3t^2$
  
  $c_1 + c_2 + 2c_3 + 6c_4 = 7$
  $-c_2 -4c_3 - 18c_4 = -8$
  $c_3 + 9c_4 = 3$
  $-c_4 = 0$
  
  $c_4 = 0$
  $c_3 = 3$
  $c_2 = -4$
  $c_1 = 12$
  
  Therefore:
  $p(t) =  \begin{bmatrix} 12 \\ -4 \\ 3 \\ 0 \end{bmatrix}$
### Example 3
  
  True or False.
  
  1.  If $\text{dim } V = n$ and $S$ is a linearly independent set in $V$, then $S$ is a basis for $V$.
  2.  If there exists a linearly dependent set $\{\mathbf{v}_1, ..., \mathbf{v}_p\}$ in $V$, then $\text{dim } V \leq p$.
  
  **Solution:**
  
  1.  **False.** If $\text{dim } V = n$ and $S$ is a linearly independent set in $V$, then $S$ is a basis for $V$ *only if* $S$ contains exactly $n$ vectors. It is true that if S has n vectors, and it is linearly independent, it would be true.
  2.  **False**. If there exists a set, S, of linearly dependent vectors, all we can say is dim V < the number of vectors in the set S. However, that number of vectors could potentially be greater than p.
### The Rank of a Matrix
  
  The **rank** of an $m \times n$ matrix $A$, denoted $\text{rank } A$, is the dimension of the column space of $A$.
  
  The dimension of $\text{Col } A$ is the number of pivot columns of $A$.
  
  Since the dimension of $\text{Row } A$ is the number of pivot rows of $A$, it is also equal to $\text{rank } A$.
### The Nullity of a Matrix
  
  The **nullity** of an $m \times n$ matrix $A$, denoted $\text{nullity } A$, is the dimension of the null space of $A$.
  
  The dimension of $\text{Nul } A$ is the number of free variables in the equation $A\mathbf{x} = \mathbf{0}$.
### Example 4
  
  Determine the dimensions of $\text{Nul } A$, $\text{Col } A$, and $\text{Row } A$.
  
  $A = \begin{bmatrix} 1 & 0 & 9 & 1 \\ 0 & 0 & 1 & -4 \\ 0 & 0 & 0 & 0 \end{bmatrix}$
  
  **Solution:**
  
  *   **Col A:** The pivot columns are the first and third columns. Therefore, $\text{dim Col } A = \text{rank } A = 2$.
  *   **Row A:** There are two nonzero rows, therefore, dim(row A) = 2.
  *   **Nul A:**  $A$ is already in echelon form.  The corresponding system of equations is:
  
    $x_1 + 9x_3 + x_4 = 0$
    $x_3 - 4x_4 = 0$
  
    The basic variables are $x_1$ and $x_3$; the free variables are $x_2$ and $x_4$. The number of free variables = dim(Nul A), Thus, $\text{dim Nul } A = \text{nullity } A = 2$.
### The Rank Theorem
  
  The dimensions of the column space and the row space of an $m \times n$ matrix $A$ are equal. This common dimension (the rank of $A$) equals the number of pivot positions in $A$ and satisfies the equation:
  
  $\text{rank } A + \text{nullity } A = n$
### Example 5
  
  If the null space of a $5 \times 6$ matrix $A$ is four-dimensional, what is the dimension of the row space of $A$?
  
  **Solution:**
  
  $A$ is a $5 \times 6$ matrix, so $n = 6$.  We are given that $\text{nullity } A = \text{dim Nul } A = 4$.
  
  By the Rank Theorem:
  
  $\text{rank } A + \text{nullity } A = n$
  $\text{rank } A + 4 = 6$
  $\text{rank } A = 2$
  
  Since $\text{rank } A = \text{dim Row } A$, the dimension of the row space of $A$ is 2.
### Example 6
  
  a. If $A$ is a $6 \times 8$ matrix, what is the smallest possible dimension of $\text{Nul } A$?
  b. If $A$ is a $6 \times 4$ matrix, what is the smallest possible dimension of $\text{Nul } A$?
  
  **Solution:**
  
  a. $A$ is $6 \times 8$, so $n = 8$.  By the Rank Theorem, $\text{rank } A + \text{nullity } A = 8$.  The largest possible value of $\text{rank } A$ is the minimum of the number of rows and columns, which is 6.  Therefore, the smallest possible value of $\text{nullity } A = \text{dim Nul } A$ is $8 - 6 = 2$.
  b. $A$ is a 6x4 matrix, so the largest possible value of rank A is 4. Because rank A + nullity A = n, this means the nullity A has smallest possible dimension of 0.
### Example 7
  
  Suppose a nonhomogeneous system of six linear equations in eight unknowns has a solution, with two free variables. Is it possible to change some constants on the equations' right sides to make the new system inconsistent? Explain.
  
  **Solution:**
  With 6 equations and 8 unknowns, the matrix describing this system is:
  $A\mathbf{x} = \mathbf{b}$ where $A$ is a 6x8 matrix.
  Because there are two free variables, nullity(A) = 2.
  Using the rank theorem:
  rank(A) + nullity(A) = # of columns
  rank(A) + 2 = 8
  rank(A) = 6
  Since the rank is 6, this means Col A spans R6 and therefore is consistent for all possible changes to constants. So the answer is no.
### Example 8
  
  Is it possible that all solutions of a homogeneous system of ten linear equations in twelve variables are multiples of one fixed nonzero solution?
  10 equations with 12 unknowns creates a 10x12 matrix.
  If there exists only one fixed nonzero solution, there are no free variables, meaning the dimension of the null space is 0.
  rank A + nullity A = n
  rank A + 0 = 12
  rank A = 12
  
  Rank cannot be higher than the number of rows, so this scenario is not possible.
### The Invertible Matrix Theorem
  
  Let $A$ be a square $n \times n$ matrix. Then the following statements are equivalent.
  
  a. $A$ is an invertible matrix.
  b. $A$ is row equivalent to $I_n$.
  c. $A$ has $n$ pivot positions.
  d. The equation $A\mathbf{x} = \mathbf{0}$ has only the trivial solution.
  e. The columns of $A$ form a linearly independent set.
  f. The linear transformation $\mathbf{x} \mapsto A\mathbf{x}$ is one-to-one.
  g. The equation $A\mathbf{x} = \mathbf{b}$ has at least one solution for each $\mathbf{b}$ in $\mathbb{R}^n$.
  h. The columns of $A$ span $\mathbb{R}^n$.
  i. The linear transformation $\mathbf{x} \mapsto A\mathbf{x}$ maps $\mathbb{R}^n$ onto $\mathbb{R}^n$.
  j. There is an $n \times n$ matrix $C$ such that $CA = I$.
  k. There is an $n \times n$ matrix $D$ such that $AD = I$.
  l. $A^T$ is an invertible matrix.
  m. The columns of $A$ form a basis for $\mathbb{R}^n$.
  n. $\text{Col } A = \mathbb{R}^n$.
  o. $\text{rank } A = n$.
  p. $\text{nullity } A = 0$
  q. $\text{Nul } A = \{\mathbf{0}\}$.
  
  We could add one more statement that the text doesn't: $\text{det } A \neq 0$.
