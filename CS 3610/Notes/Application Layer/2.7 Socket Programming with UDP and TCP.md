### **2.7 Socket Programming with UDP and TCP**
#### **Introduction to Socket Programming**
  
  *   **Goal:** To learn how to build client-server applications that communicate over the internet using sockets.
  *   **The Socket API:** A **socket** is the **Application Programming Interface (API)** that provides a "door" between the application process and the transport-layer protocols (UDP and TCP) within the operating system.
    *   The application developer controls the application process.
    *   The operating system controls the transport layer and everything below it.
    *   The socket is the one and only way for an application to directly access the internet's transport services.
  
  *   **Two Socket Types for Two Transport Services:**
    1.  **UDP Socket:** Provides an unreliable, datagram-oriented service.
    2.  **TCP Socket:** Provides a reliable, connection-oriented, byte-stream service.
  
  We will illustrate socket programming by building a simple client-server application in Python.
  *   **Application Logic:**
    1.  The client reads a line of characters from its keyboard.
    2.  It sends this data to the server.
    3.  The server receives the data and converts the characters to uppercase.
    4.  The server sends the modified data back to the client.
    5.  The client receives the modified data and displays it on its screen.

### **Socket Programming with UDP**
#### **Characteristics of UDP Sockets**
  *   **Connectionless:** There is no "connection" or handshake established between the client and server before sending data.
  *   **Explicit Addressing:**
    *   When the sender creates a packet, it must explicitly attach the destination's **IP address** and **port number** to that packet.
    *   When the receiver gets a packet, it must extract the sender's IP address and port number from the packet in order to know where to send a reply.
  *   **Unreliable:** The underlying UDP transport may cause data to be lost or received out-of-order.
#### **Client/Server Interaction with UDP**
  
  1.  **Client-Side:**
    *   Creates a UDP socket. The operating system assigns it a port number.
    *   Creates a datagram containing the message, the server's IP address, and the server's port number.
    *   Sends the datagram via its socket.
    *   Waits to receive a reply from the server.
    *   When the reply arrives, it displays the message and closes the socket.
  2.  **Server-Side:**
    *   Creates a UDP socket and explicitly binds it to a well-known port (e.g., 12000).
    *   Waits to receive a datagram from any client.
    *   When a datagram arrives, the server processes the message, extracts the client's IP address and port number from the datagram, and creates a new datagram with the reply.
    *   Sends the reply datagram back to the client.
#### **Example: Python UDP Client (`UDPClient.py`)**
  
  ```python
  from socket import *
  
  serverName = 'hostname'  # IP address or hostname of the server
  serverPort = 12000
  
  # Create a UDP socket for the client
  # AF_INET indicates we are using IPv4.
  # SOCK_DGRAM indicates this is a UDP socket.
  clientSocket = socket(AF_INET, SOCK_DGRAM)
  
  # Get input from the user's keyboard
  message = raw_input('Input lowercase sentence:')
  
  # Attach destination address to the message and send it into the socket.
  # The message must be encoded into bytes first.
  clientSocket.sendto(message.encode(), (serverName, serverPort))
  
  # Read reply characters from the socket into a string.
  # The recvfrom() method also returns the server's address.
  # 2048 is the buffer size.
  modifiedMessage, serverAddress = clientSocket.recvfrom(2048)
  
  # Print the received message after decoding it from bytes to a string.
  print(modifiedMessage.decode())
  
  # Close the socket.
  clientSocket.close()
  ```
#### **Example: Python UDP Server (`UDPServer.py`)**
  
  ```python
  from socket import *
  
  serverPort = 12000
  
  # Create a UDP socket for the server
  serverSocket = socket(AF_INET, SOCK_DGRAM)
  
  # Bind the socket to the well-known port 12000.
  # Any datagrams sent to this host on port 12000 will be directed to this socket.
  serverSocket.bind(('', serverPort))
  
  print("The server is ready to receive")
  
  # Loop forever, waiting for incoming datagrams.
  while True:
    # Read from the UDP socket into a message, also getting the client's address.
    message, clientAddress = serverSocket.recvfrom(2048)
    
    # Convert the received message to uppercase.
    modifiedMessage = message.decode().upper()
    
    # Send the modified message back to the client's address.
    serverSocket.sendto(modifiedMessage.encode(), clientAddress)
  ```

### **Socket Programming with TCP**
#### **Characteristics of TCP Sockets**
  *   **Connection-Oriented:** A client and server must first perform a handshake to establish a TCP connection before any application data can flow.
  *   **Client Must Contact Server:** The server process must be running and must have created a special "welcoming socket" that waits for clients to make contact.
  *   **The "Pipe" Analogy:** Once established, a TCP connection acts like a pipe. The client process can push bytes into the pipe, and TCP guarantees they will be delivered reliably and in order to the server process on the other end.
#### **Client/Server Interaction with TCP**
  The TCP interaction is more complex because of the connection setup.
  
  1.  **Server-Side (Setup):**
    *   Creates a "welcoming socket" (`serverSocket`) and binds it to a well-known port.
    *   Places this socket into a listening state using `listen()`. It is now ready to accept connection requests.
    *   Calls `accept()`, which is a **blocking call**. The server waits here until a client contacts it.
  2.  **Client-Side:**
    *   Creates its own TCP socket (`clientSocket`).
    *   Calls `connect()`, specifying the IP address and port of the server's welcoming socket. This triggers the **TCP three-way handshake** at the transport layer.
  3.  **Server-Side (Connection Accepted):**
    *   When the client's connection request arrives, the `accept()` call on the server unblocks.
    *   Crucially, `accept()` **creates a new, dedicated socket** (`connectionSocket`) specifically for communication with *this particular client*.
    *   The original `serverSocket` goes back to listening for new clients. This allows a single server to handle multiple clients simultaneously, each on its own dedicated socket.
  4.  **Data Transfer:** The client and server can now send and receive data reliably through their respective sockets (`clientSocket` and `connectionSocket`).
  5.  **Closure:** When finished, one side calls `close()` on its socket, which terminates the TCP connection.
#### **Example: Python TCP Client (`TCPClient.py`)**
  
  ```python
  from socket import *
  
  serverName = 'servername'
  serverPort = 12000
  
  # Create a TCP socket
  # SOCK_STREAM indicates a TCP socket.
  clientSocket = socket(AF_INET, SOCK_STREAM)
  
  # Initiate the TCP connection to the server
  clientSocket.connect((serverName, serverPort))
  
  sentence = raw_input('Input lowercase sentence:')
  
  # Send the sentence through the TCP connection's socket.
  # Note: No need to attach a destination address.
  clientSocket.send(sentence.encode())
  
  # Wait for the reply from the server.
  modifiedSentence = clientSocket.recv(1024)
  
  print('From Server:', modifiedSentence.decode())
  
  # Close the socket, which tears down the TCP connection.
  clientSocket.close()
  ```
#### **Example: Python TCP Server (`TCPServer.py`)**
  
  ```python
  from socket import *
  
  serverPort = 12000
  serverSocket = socket(AF_INET, SOCK_STREAM)
  serverSocket.bind(('', serverPort))
  
  # Make the server listen for TCP connection requests.
  # The '1' specifies the maximum number of queued connections.
  serverSocket.listen(1)
  
  print('The server is ready to receive')
  
  while True:
    # When a client knocks, create a new socket for that client.
    # The accept() method blocks until a client connects.
    connectionSocket, addr = serverSocket.accept()
    
    # Receive the client's message through the new connection socket.
    sentence = connectionSocket.recv(1024).decode()
    
    capitalizedSentence = sentence.upper()
    
    # Send the capitalized sentence back to the client.
    connectionSocket.send(capitalizedSentence.encode())
    
    # Close the connection socket for this client. The welcoming socket remains open.
    connectionSocket.close()
  ```
