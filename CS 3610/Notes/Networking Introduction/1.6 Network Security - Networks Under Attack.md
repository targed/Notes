### **1.6 Network Security: Networks Under Attack**
  
  Network security is a vast and critical field. This section serves as a high-level introduction to the fundamental threats and defenses, which will be revisited in greater detail throughout the course.
#### **The Security Mindset: Two Key Questions**
  
  When approaching network security, we focus on two primary questions:
  
  1.  **What can bad actors do?** Understanding the types of attacks and vulnerabilities that exist.
  2.  **What defenses can be designed and deployed?** Understanding the mechanisms and architectures used to prevent, mitigate, and react to these attacks.
#### **Historical Context: Security as an Afterthought**
  
  A crucial point to understand is that the internet was not originally designed with robust security in mind.
  
  *   **Original Vision:** The early internet was conceived as a "group of mutually trusting users attached to a transparent network." The primary goal was connectivity and information sharing, not defending against malicious behavior.
  *   **Playing "Catch-Up":** As a result, today's network designers are often playing "catch-up," trying to add security features to a system that was not fundamentally built to be secure. This means security considerations must be applied at all layers of the protocol stack.
#### **Common Network Attacks (What Bad Guys Can Do)**
  
  1.  **Packet Interception (Packet "Sniffing")**
    *   **Definition:** An attacker makes copies of packets as they travel across a network.
    *   **How it Works:** On a broadcast medium (like a shared Ethernet or a Wi-Fi network), an attacker can place a network interface into "promiscuous mode." This allows their device to capture and read all packets on the network, not just the ones addressed to it.
    *   **Impact:** This can reveal sensitive data, such as usernames, passwords, and other personal information, if it is not encrypted.
    *   **Tools:** Software like **Wireshark** is a legitimate packet sniffer used for network analysis but demonstrates the ease with which this can be done.
  
  2.  **Fake Identity (IP Spoofing)**
    *   **Definition:** An attacker injects packets into the network with a false source IP address to impersonate another device.
    *   **How it Works:** The attacker sends a packet to a target, but manipulates the source address in the IP header to make it appear as if the packet came from a different, often trusted, source.
    *   **Impact:** This can be used to bypass security measures that rely on IP addresses for authentication or to trick a system into revealing information or granting unauthorized access.
  
  3.  **Denial of Service (DoS) Attacks**
    *   **Definition:** An attack designed to make a network resource (such as a server or a link's bandwidth) unavailable to its legitimate users.
    *   **How it Works:** The attacker overwhelms the target with a flood of bogus traffic. The target spends all its resources (CPU, memory, bandwidth) trying to handle the attack traffic, leaving no resources to serve legitimate requests.
    *   **Distributed Denial of Service (DDoS):** A more powerful form of DoS attack. The attacker first compromises a large number of computers around the internet, creating a network of infected machines called a **botnet**. The attacker then commands the entire botnet to launch a coordinated attack, flooding the target with traffic from thousands or millions of different sources simultaneously.
#### **Lines of Defense**
  
  To counter these attacks, several defense mechanisms are used:
  
  *   **Authentication:** Proving you are who you say you are. This is the first line of defense against impersonation and unauthorized access. (e.g., passwords, SIM cards).
  *   **Confidentiality:** Ensuring that data cannot be read by unauthorized parties. This is achieved through **encryption**. It is the primary defense against packet sniffing.
  *   **Integrity Checks:** Verifying that data has not been altered or tampered with during transit. This is often accomplished using **digital signatures**.
  *   **Access Restrictions:** Limiting which users can access which resources and what actions they can perform. (e.g., password-protected VPNs).
  *   **Firewalls:** Specialized network devices ("middleboxes") that sit between a trusted internal network and the untrusted external internet. They filter incoming and outgoing traffic based on a set of security rules, blocking malicious or unwanted packets while allowing legitimate traffic to pass. They are a key tool for detecting and reacting to DoS attacks.
