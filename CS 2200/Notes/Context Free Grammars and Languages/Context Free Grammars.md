- **1. Introduction (Section 4.1)**
  
  *   CFGs are a more powerful formalism than regular grammars or regular expressions for describing languages. They form the basis for describing the syntax of most programming languages.
  *   They belong to Type 2 in the Chomsky hierarchy.
  *   **Motivation:** Regular grammars have strict restrictions on the right-hand side of production rules (e.g., single terminal or single terminal followed by single variable). To describe more complex languages (like non-regular ones), these restrictions need to be relaxed. CFGs relax the right-hand side while keeping the left-hand side simple.
  ---
- **2. Formal Definition (Definition 1)**
  
  *   A Context-Free Grammar (CFG) is formally defined as a 4-tuple:
    $G = (V, T, P, S)$
    where:
    *   $V$: A finite set of **variables** (also called **non-terminals**). These represent sets of strings or syntactic categories. They are usually denoted by uppercase letters.
    *   $T$: A finite set of **terminals** (also called the **alphabet**). These are the basic symbols that form the actual strings of the language. $V$ and $T$ must be disjoint ($V \cap T = \emptyset$).
    *   $P$: A finite set of **productions** (or **rules**). Each production has the form:
        $A \to \gamma$
        where:
        *   $A \in V$ (The left-hand side *must* be a single variable).
        *   $\gamma \in (V \cup T)^*$ (The right-hand side is a string consisting of zero or more variables and/or terminals). The string $\gamma$ is often called the **body** of the production.
    *   $S \in V$: The **start symbol** (or start variable). This is a special variable from which all derivations of strings in the language must begin.
  
  *   **"Context-Free" Meaning:** The name arises because the rule $A \to \gamma$ can be applied to replace the variable $A$ *regardless* of the context (the symbols surrounding $A$) in which it appears.
  ---
- **3. Derivations (Generating Strings)**
  
  *   CFGs are used to **generate** the strings of a language. This process is called **derivation**.
  *   **Process:**
    1.  Start with the start symbol $S$.
    2.  Repeatedly apply production rules: Find a variable $A$ in the current string (called a **sentential form**) and replace it with the right-hand side $\gamma$ of some production $A \to \gamma$ in $P$.
    3.  This continues until the string consists *only* of terminal symbols. Such a string is said to be **derived** from the start symbol.
  *   **Notation:**
    *   $\alpha \Rightarrow \beta$: String $\beta$ can be derived from string $\alpha$ in one step (by applying one production rule).
    *   $\alpha \Rightarrow^* \beta$: String $\beta$ can be derived from string $\alpha$ in zero or more steps. (Reflexive, transitive closure of $\Rightarrow$).
  ---
- **4. Language Generated by a CFG**
  
  *   The **language generated by a CFG** $G=(V, T, P, S)$, denoted $L(G)$, is the set of all strings consisting *only of terminals* that can be derived from the start symbol $S$.
  *   Formally: $L(G) = \{ w \in T^* \mid S \Rightarrow^* w \}$
  *   Any language that can be generated by a CFG is called a **Context-Free Language (CFL)**.
  ---
- **5. Examples**
  
  *   **Example 4.1: Language $a^*$**
    *   $G = (V=\{S\}, T=\{a\}, P=\{S \to aS, S \to \epsilon\}, S=S)$
    *   Derivation of "aaa": $S \Rightarrow aS \Rightarrow aaS \Rightarrow aaaS \Rightarrow aaa\epsilon = aaa$.
    *   $L(G) = \{\epsilon, a, aa, aaa, \dots\} = a^*$. (This is also a regular language).
  
  *   **Example 4.2: Palindromes over $\{a, b\}$**
    *   $G = (\{S\}, \{a, b\}, P=\{S \to \epsilon, S \to a, S \to b, S \to aSa, S \to bSb\}, S)$
    *   Derivation of "aba": $S \Rightarrow aSa \Rightarrow aba$.
    *   Derivation of "abba": $S \Rightarrow aSa \Rightarrow abSba \Rightarrow abba$.
    *   $L(G) = \{w \in \{a,b\}^* \mid w = w^R\}$ (The language of palindromes, which is not regular).
  
  *   **Example 4.3: Strings with equal numbers of a's and b's**
    *   $G = (\{S\}, \{a, b\}, P=\{S \to SaSbS, S \to SbSaS, S \to \epsilon\}, S)$
    *   Derivation of "abab": $S \Rightarrow SaSbS \Rightarrow \epsilon a SbS \Rightarrow a \epsilon b S \Rightarrow ab \epsilon = ab$. (Seems complex, maybe example derivation needed. Let's try "baab"): $S \Rightarrow SbSaS \Rightarrow \epsilon b SaS \Rightarrow b \epsilon a S \Rightarrow ba \epsilon = ba$. (This grammar generates strings with equal #a's and #b's, but it's complex and potentially ambiguous). A simpler grammar is often $S \to aSbS \mid bSaS \mid \epsilon$.
    *   This language is context-free but not regular.
  
  *   **Example 4.4: Syntactically correct algebraic expressions with variables x, y, z and operators +, -, ***
    *   $V = \{S, T\}$ (S for sum/difference expression, T for term/product expression)
    *   $T = \{+, *, (, ), -, x, y, z\}$
    *   $P$:
        *   $S \to T + S \mid T - S \mid T$ (An expression is a term plus/minus expression, or just a term)
        *   $T \to T * T \mid (S) \mid x \mid y \mid z$ (A term is a term times term, or a parenthesized expression, or a variable) *(Note: the grammar in the text $T \to T*T|T|T$ seems like a typo, likely meant $T \to T*T \mid F$ and $F \to (S) \mid x \mid y \mid z$ or similar for factors)*. Assuming a structure like:
            $S \to S+T \mid S-T \mid T$
            $T \to T*F \mid F$
            $F \to (S) \mid x \mid y \mid z$
    *   $S$ is the start symbol.
    *   This grammar can generate strings like `(x+y)*x - z*y` or `(x+x)`.
  
  *   **Example 4.5: Strings over $\{a, b\}$ with an unequal number of a's and b's**
    *   $V = \{S, U, V, T\}$ (S=Start, U=More a's, V=More b's, T=Equal a's/b's)
    *   $T = \{a, b\}$
    *   $P$:
        *   $S \to U \mid V$ (Target language is union of more a's or more b's)
        *   $U \to TaU \mid TaT$ (Generate equal part, add 'a', then more a's part OR generate equal part, add 'a', then equal part)
        *   $V \to TbV \mid TbT$ (Similar logic for more b's)
        *   $T \to aTbT \mid bTaT \mid \epsilon$ (Generates strings with equal numbers of a's and b's)
    *   $S$ is the start symbol.
    *   This cleverly constructs the language by ensuring an imbalance is introduced via U or V rules.
